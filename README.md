# English Lab — пакет для GitHub Pages

Это готовый статический сайт. Сервер, база данных, сборка и npm не нужны.

## Состав

- `index.html` — весь сайт в одном автономном HTML-файле.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.
- `README.md` — эта инструкция.

## Самый простой способ опубликовать

1. Войдите на GitHub и создайте новый репозиторий, например `english-lab`.
2. Выберите **Public** (для обычного бесплатного GitHub Pages это самый простой вариант).
3. Нажмите **Add file → Upload files** и загрузите `index.html`, `.nojekyll` и `README.md` из этого пакета.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - папка: `/ (root)`
7. Нажмите **Save**.
8. Через несколько минут GitHub покажет адрес сайта вида:
   `https://ВАШ_ЛОГИН.github.io/english-lab/`

## Если хотите адрес без имени репозитория

Создайте репозиторий с точным названием:

`ВАШ_ЛОГИН.github.io`

Тогда адрес будет:

`https://ВАШ_ЛОГИН.github.io/`

## Важно

- Не переименовывайте `index.html`: GitHub Pages открывает именно этот файл как главную страницу.
- Сайт не использует CDN, внешние библиотеки или внешние шрифты для основной работы.
- Интерактивная часть работает в браузере на стороне пользователя.
- Данные/черновики, которые сохраняются через браузер, остаются локальными у пользователя и не синхронизируются через GitHub.
- Внешние ссылки на источники, если они есть в разделе «Цели», требуют интернета только при переходе по ним.
- После любых изменений `index.html` достаточно снова загрузить/заменить файл в репозитории и сделать Commit.

## Проверка перед публикацией

Можно сначала дважды кликнуть по `index.html` на компьютере. Если платформа открывается локально, тот же файл будет работать на GitHub Pages.
